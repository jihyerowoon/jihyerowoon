# 연구자 승인: 통합 반 관리와 자동 수업 운영 (mvp-0.5.0)

2026-10-27 연구 책임자가 UI 시안과 다음 사항을 승인했다: 한 화면에서 반 및 학생 등록, 개별/CSV 등록, 교사 코드 T1 배정, 통제집단 다중 선택 발문 전송, 실험집단 운영 모니터링, 서버 시각에 따른 자동 단계 전환, 60분 이후 별도 보완 5분, Read 영상 팝업, 문제 선택 없는 이해도 및 한 문장 성찰.

## 사용 흐름

1. 연구자로 로그인 → 반과 학생 등록 → 반 코드, 집단, 교사 코드 저장.
2. 학생 코드 및 PIN을 개별 입력하거나 `code,pin` 두 열 CSV로 등록한다. 빈 PIN은 자동 발급한다. 다른 반과 겹친 학생 코드는 이동/덮어쓰기 대신 행별 오류로 알린다.
3. 차시 및 선택 사항인 Read 영상 주소를 입력하고 수업 준비하기를 누른다. 교사 화면에서 수업 시작을 누르기 전까지는 대기한다.
4. 교사는 기존 교사 비밀번호 및 배정 코드(T1)로 로그인하고 해당 수업을 선택한다. 연구자도 수업 운영에서 바로 들어갈 수 있다. 새로고침 시 운영 화면을 복원한다.
5. 통제집단은 같은 문항의 학생 답안들을 확인하고 체크한 뒤 발문을 선택해 개별 메시지로 일괄 전송한다. 모든 성공/실패 결과가 학생별로 표시된다. 실험집단에 대한 교사의 수학 발문은 서버에서 차단한다.
6. 학생은 기존 수업 코드, 학생 코드, PIN으로 입장한다. 등록 명단을 CSV로 내려받을 수 있으며 PIN은 연구자 전용 API에서만 제공된다.

## 시간과 자료 보존

- 기존 수업을 자동으로 전환하지 않는다. 새 반에서 생성된 수업에만 autoTimer를 적용한다.
- 1, 2차시의 기존 60분 배분 [2,2,16,19,9,12] 및 기존 정답 공개(Review +6분), 성찰(+10분) 시점을 유지한다.
- 서버의 절대 종료 시각으로 전환을 결정한다. 학생/교사의 폴링과 API 요청에서 기한을 확인하고 행 잠금으로 전환을 직렬화한다. 장시간 모두 오프라인인 경우 다음 요청에서 누락된 전환을 원래 예정 시각 기준으로 처리한다. 브라우저 자체 타이머/크론에 의존하지 않는다. 화면 표시는 네트워크와 폴링에 따른 지연이 있을 수 있다.
- 1분 및 10초 알림, 큰 남은 시간 표시, 자동 이동 안내를 제공한다. 정지는 비상용이며 정지/재개 이력을 저장하고 남은 시간을 복원한다.
- 마지막 Review 종료 시 MAIN_TIME_SNAPSHOT을 학생별로 추가한 후 보완 5분을 연다. 보완은 supplements 표 및 SUPPLEMENT_SAVED 이벤트에만 저장하며 item_states와 기존 제출 이력은 변경하지 않는다. 두 집단 모두 추가 발문을 제공하지 않는다.
- 보완 답안은 정답 공개 이후 작성되는 자료이므로 시간 내 수행과 합쳐 성취도 점수로 간주하면 안 된다. extra.analysis_phase 및 after_answer_release를 기록한다.
- 시간이 지나 거부된 초안은 저장 성공으로 표시하지 않는다. 기기에 남은 입력은 보완 화면에 표시한다. 최종 입력이 네트워크 실패로 서버에 도착하지 못한 경우 원래 시점의 데이터로 소급 저장하지 않는다.
- 성찰은 이해도와 한 문장만 입력한다. 자동 저장 초안 이벤트와 최종 제출 이벤트를 구분한다. 예전 focus_item이 있는 이벤트도 읽을 수 있다.
- events의 추가 전용 트리거와 기존 CSV 필드 순서를 유지한다. 신규 표/열만 추가하고 백업에 반 배정, 시계, 보완 자료를 추가한다.

## 영상

- Read에 진입하면 페이지 안 dialog를 열고 학생의 클릭으로 재생한다. 다시 보기 버튼을 제공한다.
- YouTube는 youtube-nocookie.com, Vimeo는 player.vimeo.com으로 변환한다. 직접 mp4/webm/ogv 주소는 video 요소로 연다. 그 외 주소는 안전한 새 창 링크를 제공한다.
- CSP는 두 영상 호스트의 frame-src 및 HTTPS media-src만 추가한다. 외부 자바스크립트는 추가하지 않는다.
- VIDEO_PLAY는 재생 버튼을 눌렀다는 기록이며 실제 완강 여부를 입증하지 않는다. 실제 수업 영상 링크는 아직 제공되지 않았으며 호스팅 서비스의 임베드 제한/저작권/로그인 조건에 따라 재생 가능 여부가 달라질 수 있다.

## mvp-0.5.1 (2026-10-28): 학생은 반 코드로 입장

- 학생 입력은 반 코드, 학생 코드, PIN 세 개다. 차시나 생성된 수업 코드를 입력하지 않는다.
- 인증 후 해당 학생이 소속된 반에서 교사가 시작한 자동 수업(진행/정지/보완)에 연결한다. T1과 T01은 서로 다른 반으로 유지하며 학생/집단/기존 기록을 합치지 않는다.
- 시작 전에는 대기 안내 후 4초마다 자동 재확인한다. PIN은 이 재시도 동안 입력칸과 메모리에서만 사용하며 새로 로컬 저장하지 않는다. 입력 변경이나 화면 이탈 시 재시도하지 않는다.
- 같은 반의 두 자동 수업 동시 시작은 서버에서 차단한다. 이미 복수 활성 수업이 존재하면 임의의 차시에 배정하지 않고 교사 확인을 요청한다.
- 기존 session_code API는 호환성을 위해 유지한다. 새 화면은 class_code를 명시적으로 사용해 반 이름과 수업 이름이 같아도 충돌하지 않는다.
- 격리 PGlite에서 tests/class-entry.test.js 19항목 통과: 실제 형식 T1/T01 및 학생 T01/T02/T04, PIN1111, 소문자, 시작 대기, 교사 선택 2차시 입장, 타반 차단, 두 수업 동시 시작 차단, 정지 중 재입장, 구형 API, 복수 활성 수업 검증. 기존 Review 공개와 발문 은행 잠금 회귀 검사도 통과했다. 운영 DB 데이터는 읽거나 변경하지 않았다.

## mvp-0.5.2 (2026-10-28): 시연 처음부터와 학생 명단 안내

- 기존 `수업 준비하기`는 같은 반/차시의 열린 수업을 재사용하므로 Read 진입 및 경과 시간이 재접속 시 유지되는 것이 원인이었다. 버튼을 `수업 준비 / 이어하기`로 구분하고 `시연 처음부터`를 별도로 추가했다.
- 새 시연은 DEMO 접두사의 별도 세션이다. 반과 학생 명단은 재사용하고 답안/진행/시작 시간은 이전 세션에서 가져오지 않는다. Preview 단계에서 기다리며, 교사가 시연 시작을 누르기 전에는 타이머가 흐르지 않는다. 학생도 이 대기 상태에서 반 코드로 입장할 수 있다.
- 같은 반의 진행 중 수업을 교사가 명시적으로 선택하고 확인한 경우에만 그 수업을 종료하고 새 시연을 만든다. 다른 진행 중 수업을 임의로 닫지 않는다. 이전 item_states, 제출본, events는 수정/삭제하지 않는다. 시연 대기 세션은 하나만 남겨 입장 혼선을 방지한다.
- 시연 운영 화면에서도 시연 처음부터를 제공한다. 이전 세션에 로그인되어 있던 학생은 종료를 인지해 입장 화면으로 돌아가고 같은 반/학생 코드/PIN으로 새 Preview에 들어간다. 단순 새로고침/재접속은 진행 중인 수업을 초기화하지 않는다.
- 화면을 새 시연으로 전환한 후 도착하는 이전 교사/학생 동기화 응답은 무시한다. 오래된 Read 상태가 새 시연 화면을 덮어쓰는 상황을 방지한다.
- 선택한 반의 학생 목록 제목을 `반 코드에 등록된 학생`으로 변경했다. 새 반은 빈 명단으로 시작하고, 같은 반의 여러 차시와 시연에서는 명단을 그대로 사용함을 명시했다.
- HTML과 app.js의 재검증 캐시 헤더 및 스크립트 버전 쿼리를 추가했다.
- 격리 DB에서 tests/demo-start.test.js 21항목, 기존 반 입장 19항목, Review 36항목, 발문 은행 잠금, 지원 정책 16항목, 활동지 회귀 검사를 통과했다. tests/demo-ui.test.js는 실제 Chromium에서 새 시연 준비, 시작 전 학생 입장, Preview 2분, Read 진행, 처음부터 재시작 후 재입장을 검증한다. 운영 DB 데이터에는 접근하거나 시연을 생성하지 않았다.

## mvp-0.5.3 (2026-10-28): 교사와 연구자 자동로그인

- 교직원 인증 유효기간을 12시간에서 180일로 바꾸고, 자동 접속 때 서버에서 검증한 뒤 새 180일 인증으로 갱신한다. 기존 유효한 12시간 인증도 자동 이행한다.
- 이 브라우저의 교사/연구자 인증을 역할별 별도 localStorage에 보관한다. 학생 시연이 공통 마지막 로그인 정보를 바꿔도 교직원 기억은 유지된다. 새 탭은 마지막 교직원 역할을 먼저 복원하고 기존 학생 탭은 그 탭의 로그인 상태를 유지한다.
- 한 번씩 인증한 교사와 연구자 탭은 시작 화면에서 클릭하면 비밀번호 없이 서버 검증 후 들어간다. 일반 루트 주소는 자동로그인하고 명시적인 #login 주소는 시작 화면을 표시한다.
- 비밀번호는 브라우저에 저장하지 않는다. 저장하는 것은 서명된 인증 토큰이다. 비밀번호를 변경하면 서버 지문 검증으로 이전 교직원 토큰을 거부한다. 학생은 교직원 인증 갱신 API를 사용할 수 없다.
- 직접 로그아웃하면 해당 역할의 기억을 지우고 다른 저장된 역할로 즉시 다시 들어가지 않는다. 만료, 사이트 데이터 삭제, 서버 인증 설정 변경 시에는 다시 로그인이 필요하다. 네트워크 오류만으로 저장된 인증을 지우지는 않는다.
- tests/staff-remember.test.js 15항목을 격리 환경에서 통과했다. 실제 Chromium의 tests/staff-remember-ui.test.js에서 새 탭/브라우저 상태 복원, 두 역할의 별도 기억과 전환, 학생 로그인 뒤 교직원 기억 유지, 명시적 로그아웃을 검증한다.
