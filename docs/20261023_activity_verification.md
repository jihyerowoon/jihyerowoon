## 서버 / UI 코드에 반영한 내용
- 1·2차시 각 60분. PQ4R 배분 [2,2,16,19,9,12].
- Review 첫 6분 동안 학생 스스로 문제풀이. 답변 및 정답 공개 전 확신도 3점 응답을 **같은 RV01 제출 기록에 저장**.
- Review +6분 정답/해설 5문항 공개. 정답 서버 모듈: lib/review.js, 보호 API: api/router.js 및 lib/student.js.
- Review +6~10분 문제·본인 기존 답안·공통 풀이 대조.
- Review +10분 후 성찰지 문항: 이해 정도 3택 1, 해설 대조 후 새롭게 알게 된 조건/성질 또는 여전히 어려운 점 1~2문장. 기존 지원 로그와 구분된 REVIEW_POST_REFLECTION 이벤트 기록.
- 실험집단/통제집단 모두 동일한 정답과 성찰 UI. Reflect에서도 사전 준비된 고정 검토자료 공동 적용.
- 정답 공개 전 답변에 대한 confidence와 공개 후 설명 가능성 평정은 서로 다른 질문이므로 동일 척도 변화 점수로 단순 비교하면 안 된다.

## 업로드 중요: PPTX는 직접 연결되지 않음
- 현재 연구자 UI에는 'PPTX 활동지 업로드' 버튼이 없다.
- 앱의 실제 인터랙티브 문항과 도형은 lib/content.js, public/figures, public/materials로 구현돼 있다.
- 사용자 제공 PPTX를 시각적으로 똑같이 보여주려면 학생용 원본을 고해상도 PNG로 렌더링해 화면 컴포넌트에 연결하는 개발 작업이 더 필요하다.
- **정답/해설 PPTX와 그 이미지 파일을 GitHub의 public/, Vercel의 public/에 두지 말 것.** URL만 알면 6분 공개 이전에 접근할 수 있다.
- 정답 본문은 현재 lib/review.js 서버 전용 코드로 관리하며 REST API에서 Review+360초 이전 접근을 차단한다.
- GitHub 파일 업로드는 현재 브랜치 research-20261023-single-level-a를 택한 뒤 Add file > Upload files > Commit changes. 대용량 파일/민감한 정답은 보호 저장소에만 업로드.
- student/ 이미지 원본을 브랜치에 업로드했다는 사실만으로 자동 반영되지는 않는다. 학생 화면 렌더 코드에서 해당 파일을 참조해야 한다.

## 발견된 수정 사항
1. 기존 PPTX 1차시 정답지의 Read / Reflect 분홍색 표제가 폭이 좁아 잘려 보였다. 텍스트 박스 너비를 넓힌 수정 PPTX를 별도로 제작하였다. 수학 문장/도형/정답은 변경하지 않음.
2. 학생 Review 활동지는 정답 공개 전 확신도 3택 1을 포함하지만, 기존 웹에는 없었다. 이번 브랜치에서 RV01 필드로 추가.
3. 모든 본문과 도형의 웹 표시 정밀도, 30명 동시 접속, DB 기록·시간 게이트는 실제 Vercel 시연/통합 테스트를 거친 뒤 main에 병합한다.
