# 2026년 10월 23일 | 수학 개념 연계형 메타인지 단일수준 발문은행 검토 초안

> **검토 필요.** 학생 상태 판정은 연구용 시범 기준이며, 모든 발문은 학생에게 풀이 방법이나 정답을 직접 알려주지 않도록 추가 검수해야 함.

## 교수지원 운영 원칙
- 대상: 중학교 2학년 1·2차시의 **활성 문항 24개**.
- 발문: 문항당 16개, Reflect에서는 18개. 총 **396개**.
- 전 발문은 메타인지 질문 한 유형, 지원 강도 단일 수준 **1**로 기록됨. 과거 은행의 2~4수준은 과거 자료 보존용이며 실제 지원에서 미사용.
- 개념 영역을 주의 초점으로 알려주되, 특정 수학 성질·정답·수치를 직접 제시하지 않음.
- 학생 최초 제출 → 도움 요청 → 같은 수준의 문항별 질문 → 재응답 → 추가 도움 요청. 반복 도움은 횟수 제한 대신 수업 단계 시간 종료로 제한됨.
- AI 개별 튜터는 승인된 질문은행에서 자동으로 선택하며, 교사는 통제집단 학생 30명의 요청 중 한 명에게 같은 은행에서 질문을 선택해 **학생의 화면에 텍스트로 전송**.
- **교사 구두 발문 의무는 구현되지 않음.** 교사 1명 대 30명 Zoom 전체 방송에서 개별 질문을 읽으면 비교집단에 대한 처치 오염이 발생할 수 있음. 연구 목적으로 구두 전달을 의무화하려면 개별 전달 방법 및 자기보고가 아닌 이행검증 방법을 먼저 확정해야 함.
