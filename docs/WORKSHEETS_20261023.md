# 2026-10-23 연구용 활동지 반영 확인

사용자가 최종 제출한 활동지 4종을 기준으로 1·2차시를 구성한다.
- 1차시 AI지원: `1차시_AI지원_삼각형의 합동(2).pptx`
- 1차시 교사지원: `1차시_교사지원_삼각형의합동(3).pptx`
- 2차시 AI지원 최신판: `2차시_AI지원_평행사변형의 성질(2).pptx`
- 2차시 교사지원 첨부본: `2차시_교사지원_평행사변형의 성질.pptx`

## 1·2차시 공통 시간
Preview 2분, Question 2분, Read 16분, Reflect 19분, Recite 9분, Review 12분. 총 60분.

## 근거와 주의
- 마지막 2차시 AI지원 파일은 앞서 받은 `(1)` 파일과 비교하여 4쪽의 집단명 표시가 변경되어 있다.
- 현재 첨부된 2차시 교사지원 PPTX에는 2·3쪽 Read 12분, 7쪽 Reflect 10분, 9쪽 Review 10분이라는 이전 표기가 일부 잔존한다. 해당 파일의 최종 교정 여부를 연구자에게 재확인한 뒤 PDF/PPTX 제공 자료를 수정할 것. 웹앱 시간은 두 차시 60분으로 일치시킨다.
- Reflect에서는 두 집단에 동일한 문제, 사전 검증 설명, 판단 문항과 입력란을 제공한다. AI가 실시간 생성한 해설로 표시해서는 안 된다.
- 이미지/동영상 자체를 교체하지 않았으며 정답키와 발문은행은 별도 검수를 요구한다.
- 코드 수정은 이 작업 브랜치에서만 수행한다. main 배포 금지.

점검: `node tests/research-worksheet.test.js` 실행 후 결과 확인. 기존 `tests/engine.test.js`는 오래된 54분·0~4 수준 기대값이 있으므로 새로운 연구설계에 맞게 별도 개정이 필요하다.
